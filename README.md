## 🏡 Overview

**AntixorHome** is a modern real estate web platform designed to deliver a smooth and visually engaging property discovery experience.

With a contemporary interface, responsive layouts, and reusable components, the project brings together modern frontend technologies to create an attractive digital experience for exploring real estate.

Whether browsing properties or exploring a new living space, AntixorHome focuses on simplicity, usability, and elegant presentation.

---

## ✨ Features

- 🏘️ **Modern Real Estate UI** — A clean and contemporary property browsing experience.
- 🎨 **Premium Visual Design** — Attractive layouts and carefully crafted styling.
- 📱 **Responsive Interface** — Designed for desktop, tablet, and mobile screens.
- ⚡ **Fast Performance** — Powered by Vite for efficient development and production builds.
- ⚛️ **Reusable Components** — Built with React for maintainable UI development.
- 🔷 **Type Safety** — TypeScript helps maintain reliable and structured code.
- 🎯 **Interactive Elements** — Modern UI interactions with Lucide icons and Motion.
- 🧩 **Scalable Architecture** — A foundation for future real estate features.

## ⚙️ Installation

Run AntixorHome locally using the following steps.

### Prerequisites

- Node.js compatible with your Vite version
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/GhousDeveloper/AntixorHome.git
```

### 2. Navigate to the Project

```bash
cd AntixorHome
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local address displayed in your terminal. The development server is configured to use port `3000`.

### 5. Build for Production

```bash
npm run build
```

### 6. Preview the Production Build

```bash
npm run preview
```

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Creates a production build |
| `npm run preview` | Previews the production build |
| `npm run lint` | Runs the TypeScript compiler checks |
| `npm run clean` | Removes the build output and `server.js` on supported shell environments |

**Note:** The repository URL above is an example. Replace it if your actual GitHub repository has a different URL.
